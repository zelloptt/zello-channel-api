Class: OutgoingMessage

OutgoingMessage

Outgoing audio message class. Instances are returned from Session.startVoiceMessage method. A message goes to one channel (options.channel, or the session default) or to several at once (options.channels): one stream is opened per channel and every encoded frame is sent to each of them. Channels that refuse the stream are reported through stream_failed and left out; the message fails only when none accepts.

start()

Starts an outgoing message if options.autoStart is true (default behaviour) then message is started automatically when instance is created by session.startVoiceMessage Opens one stream per channel. Resolves with {stream_id, streams}: the first accepted stream id, and per channel either {stream_id} or {error}. Rejects only when no channel accepted.

Example
// callback
outgoingMessage.stop(function(err, result) {
  if (err) {
    console.trace(err);
    return;
  }
  console.warn('Message stopped');
});

// promise
outgoingMessage.then(function(result) {
  console.warn('Message stopped');
}).catch(function(err) {
  console.trace(err);
});
