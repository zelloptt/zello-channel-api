Interface: Recorder

Recorder

Recorder interface. Recorder is used by OutgoingMessage to record and send voice data. A custom recorder (startVoiceMessage({recorder: MyRecorder})) is constructed with the message options and the encoder, and implements:
  • init(): opens the input; returns a promise that rejects when it cannot.
  • start(): called once the server has accepted the stream.
  • stop(): releases the input and tells the encoder the input is over (encoder.postMessage({command: 'done'})).
  • getSampleRate(): the rate of the PCM it hands over.
and calls the hooks OutgoingMessage assigns on its prototype:
  • onready() once the input is open;
  • ondata(buffers) with one Float32Array per channel for each PCM portion;
  • optionally onprogress(sentMs, totalMs) while a bounded input is going out, and onend() once it is exhausted, which ends the message.
This class records the microphone; ReplayRecorder plays back PCM already in memory through the same interface, using the two optional hooks. types/zcc.d.ts declares the shape as ZCC.Recorder.
