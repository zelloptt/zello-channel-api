Class: Session

Session(options) → {ZCC.Session}

Session class to start a session with the Zello server and interact with it using the Zello Channel API

Constructor

new Session(options) → {ZCC.Session}

Parameters:
Name Type Description
options object session options. Options can also include player, decoder, recorder and encoder overrides. options.channels is the list of channel names to connect to. When it is omitted, the session connects to options.channel only and stores that name as a one-item list. options.channel is the default channel for outgoing messages. It must be a channel name, and one of options.channels when both are set. When options.channels is set and options.channel is omitted, there is no default until the caller sets one. options.muteIncomingAudio keeps incoming voice messages silent while still raising their events, for a session that only sends.

playDispatchMessage(callId, messageId, channelOrCallbackopt, userCallbackopt) → {promise}

Plays back one message from a pending or taken dispatch call. The server downloads the recorded audio and delivers it like any incoming voice message: incoming_voice_will_start fires with a message whose data carries call_id and message_id, followed by the audio and incoming_voice_did_stop.
Parameters:
Name Type Attributes Default Description
callId Number the ID of the dispatch call the message belongs to.
messageId Number the ID of the message to play, from the call's messages list returned by getDispatchCalls.
channelOrCallback String | function <optional>
 null channel the call lives on, or the completion callback. A channel name targets that channel instead of the session default.
userCallback function <optional>
 null completion callback, used when the third argument is a channel name.
Source:
  • session.js, line 993
Returns:
promise that resolves with {success, stream_id} once playback starts and rejects if it failed. startVoiceMessage(options, userCallbackopt) → {ZCC.OutgoingMessage}

Starts a voice message by creating OutgoingMessage instance
Parameters:
Name Type Attributes Default Description
options object options for outgoing messages. Options can also include recorder and encoder overrides.
userCallback function <optional>
 null callback called once the voice message has been started or failed to start.
Source:
  • session.js, line 795
Returns:
OutgoingMessage object
Type
ZCC.OutgoingMessage
Example
// use default recorder and encoder
var outgoingMessage = session.startVoiceMessage();

// send one message to several channels the session joined; each channel
// reports through the message's stream_started / stream_failed events
var outgoingMessage = session.startVoiceMessage({
  channels: ['Baker Street 221B', 'Reichenbach Falls']
});

// send audio already in memory (a recorded announcement) at real-time pace;
// the message stops itself after the last sample
var outgoingMessage = session.startVoiceMessage({
  channels: ['Baker Street 221B', 'Reichenbach Falls'],
  replay: {samples: recordedPcm, sampleRate: 48000}
});

// use custom recorder
var outgoingMessage = session.startVoiceMessage({
  recorder: CustomRecorder
});

// use custom recorder and encoder
var outgoingMessage = session.startVoiceMessage({
  recorder: CustomRecorder,
  encoder: CustomEncoder
});

// specify custom talk priority
// standard values are talkPriorityNormal and talkPriorityLow
var outgoingMessage = session.startVoiceMessage({
  talkPriority: ZCC.OutgoingMessage.talkPriorityNormal
});
