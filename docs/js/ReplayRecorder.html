Class: ReplayRecorder

ReplayRecorder(options, encoder)

A Recorder that plays back PCM already in memory instead of opening the microphone, at the pace it was captured, so a recorded announcement can be sent through Session.startVoiceMessage like a live one. The server drops a stream whose packets arrive much faster than real time, so the samples are handed to the encoder one frame per frame interval. Picked automatically when startVoiceMessage is given a replay option:

Example
var message = session.startVoiceMessage({
  channels: ['Baker Street 221B', 'Reichenbach Falls'],
  replay: {
    samples: recordedPcm,   // Float32Array, mono, -1..1
    sampleRate: 48000       // the rate the samples were captured at
  }
});
message.on('replay_progress', function(sentMs, totalMs) { ... });
// the message stops itself once the last sample has gone out; the outcome
// arrives through the message's 'stopped' or 'stop_failed' event
message.on('stopped', function(result) { ... });
message.on('stop_failed', function(err) { ... });
